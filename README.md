# Gossip Cafe

Gossip Cafe is a local React and Vite website for the cafe in Mumbra, Thane.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The menu, authentication demo, and table
reservations use browser data and local storage, so no external application
backend is required.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```
